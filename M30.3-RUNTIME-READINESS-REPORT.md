### C.3 Snapshot Comparison & Variance Detection

**Code Path:**
```
ComparisonEngine.compare(netbox_inventory, live_snapshot)
  ↓
InventoryMatcher.match()
  - Match by name (normalized)
  - If no match, try serial number
  → InventoryMatch {matched_devices, missing_devices, unexpected_devices}
  ↓
Parallel Comparators:
  ├─ IdentityComparator — duplicate detection
  ├─ DeviceComparator — serial, IP, model, platform
  ├─ InterfaceComparator — name, status, description, speed
  ├─ VLANComparator — VLAN ID, name, status
  ├─ NeighborComparator — CDP/LLDP neighbors (unsupported, marked as UNSUPPORTED)
  └─ PlatformComparator — platform field
  ↓
DifferenceRegistry aggregates all differences
  ↓
Difference Types Detected:
  - MISSING: Device/Interface/VLAN in NetBox but not discovered
  - UNEXPECTED: Device/Interface/VLAN discovered but not in NetBox
  - MODIFIED: Same object but attributes differ
  - CONFLICT: (Reserved, not currently detected)
  - DUPLICATE: Duplicate identities in same inventory
  - UNSUPPORTED: Relationships not yet modeled (e.g., neighbors)
  ↓
EvidenceGenerator.from_difference()
  - Create Evidence with details, reference, captured_at
  ↓
ComparisonEngine._finding_from_difference()
  - Assign severity (HIGH/MEDIUM/INFO)
  - Create Finding with recommended actions
  ↓
InventoryComparisonResult
  - differences: tuple[Difference, ...]
  - findings: tuple[Finding, ...]
  - metrics: ComparisonMetrics
```

## Appendix B: Glossary

| Term | Definition |
|------|-----------|
| **Expected State** | Canonical network inventory from NetBox (source of truth) |
| **Observed State** | Live network inventory from collector discovery |
| **Snapshot** | Immutable point-in-time inventory (expected or observed) |
| **Variance** | Difference between expected and observed (MISSING/UNEXPECTED/MODIFIED/etc.) |
| **Finding** | Compliance domain record of a variance with severity and evidence |
| **Evidence** | Detailed capture of how/when a variance was detected |
| **Discovery Run** | One execution of the collector runtime against real devices |
| **Comparison Result** | Result of comparing two snapshots, includes differences and findings |
| **Immutable Persistence** | Append-only database storage with no updates/deletes |
| **Lineage** | Historical chain of discovery runs → snapshots → comparisons → findings |
