## 3. NetBox vs Real-Network Comparison Engine

### Comparison Engine

**Class:** [backend/app/comparison/engine.py](backend/app/comparison/engine.py) :: `ComparisonEngine`
- **Method:** `compare(netbox: NetBoxInventorySnapshot, live: LiveInventorySnapshot)` → `InventoryComparisonResult`
- **Process:**
  1. Match NetBox devices to live devices by name/serial
  2. Run 6 parallel comparators (identity, device, platform, interface, vlan, neighbor)
  3. Collect all differences into registry
  4. Generate findings from differences
  5. Calculate metrics
  6. Return `InventoryComparisonResult`

### Comparator Implementations

#### 1. IdentityComparator
**File:** [backend/app/comparison/comparator.py](backend/app/comparison/comparator.py)
- **Purpose:** Detect duplicate device identities
- **Checks:** Duplicate names in NetBox or live snapshots
- **Difference Types:** DUPLICATE

#### 2. DeviceComparator
- **Purpose:** Compare device-level attributes
- **Checks:**
  - Missing: Device in NetBox but not found live
  - Unexpected: Device in live but not in NetBox
  - Modified fields on matched devices:
    - `serial` (Serial number)
    - `primary_ip` (Management IP)
    - `model` (Device model)
- **Difference Types:** MISSING, UNEXPECTED, MODIFIED

#### 3. InterfaceComparator
- **Purpose:** Compare interface inventory and status
- **Checks per device pair:**
  - Missing interfaces (in NetBox but not live)
  - Unexpected interfaces (in live but not in NetBox)
  - Modified fields on matched interfaces:
    - `enabled` (Admin status: up/down)
    - `mac_address` (Hardware address)
    - `description` (Interface description)
- **Difference Types:** MISSING, UNEXPECTED, MODIFIED

#### 4. VLANComparator
- **Purpose:** Compare VLAN inventory across network
- **Checks:**
  - Missing VLANs (in NetBox but not found on any live device)
  - Unexpected VLANs (on live devices but not in NetBox)
  - Modified VLAN attributes:
    - `name` (VLAN name)
    - `status` (VLAN status)
- **Difference Types:** MISSING, UNEXPECTED, MODIFIED

#### 5. PlatformComparator
- **Purpose:** Compare OS/platform information
- **Checks:** Device platform field (e.g., ios-xe, ios-xr, nxos)
- **Difference Types:** MODIFIED

#### 6. NeighborComparator
- **Purpose:** Flag neighbor data (not available from NetBox)
- **Checks:** Mark all observed neighbors as UNSUPPORTED (requires external validation)
- **Difference Types:** UNSUPPORTED

### Inventory Matching

**Class:** [backend/app/comparison/matcher.py](backend/app/comparison/matcher.py) :: `InventoryMatcher`
- **Method:** `match(netbox, live)` → `InventoryMatch`
- **Logic:**
  1. Normalize device names (strip, lowercase)
  2. Detect duplicates
  3. Match by name; fallback to serial number
  4. Return matched pairs + unmatched/unexpected sets

## 4. Variance Model

### Difference Types

**Enum:** [backend/app/comparison/diff.py](backend/app/comparison/diff.py) :: `DifferenceType`

| Type | Meaning | Example |
|------|---------|---------|
| MISSING | Expected but not observed | Device in NetBox missing from live |
| UNEXPECTED | Observed but not expected | Rogue device found live, not in NetBox |
| MODIFIED | Changed attribute | Serial number mismatch |
| CONFLICT | Data integrity issue | Ambiguous match |
| DUPLICATE | Identity collision | Device name appears multiple times |
| UNSUPPORTED | Cannot validate | Neighbor data without NetBox baseline |
| UNKNOWN | Unexpected case | Future variance types |

### Difference Record

**Class:** [backend/app/comparison/diff.py](backend/app/comparison/diff.py) :: `Difference`

```python
@dataclass(frozen=True)
class Difference:
    difference_type: DifferenceType      # Type of variance
    subject_type: str                     # "device", "interface", "vlan", etc.
    subject_id: str                       # Device/interface/vlan identifier
    field_name: str | None                # Which attribute changed
    expected: object | None               # Expected value
    observed: object | None               # Observed value
    description: str | None               # Human-readable summary
    metadata: Mapping[str, object]        # Additional context
    id: UUID                              # Immutable record ID
    detected_at: datetime                 # When difference was found
```

**Class:** [backend/app/comparison/result.py](backend/app/comparison/result.py) :: `InventoryComparisonResult`

```python

```

Each difference is converted to a finding with:

### Workflow Persistence Integration

**Workflow:** [backend/app/orchestration/workflow.py](backend/app/orchestration/workflow.py) :: `WorkflowEngine._persist()`

```python
def _persist(self, job, netbox_inventory, live_inventory, comparison_result):
    with self.unit_of_work_factory() as unit_of_work:
        discovery_run = unit_of_work.history.create_discovery_run(
            str(job.context.run_id),
            metadata=job.context.metadata,
        )
        netbox_snapshot = unit_of_work.snapshots.add_netbox_snapshot(
            netbox_inventory
        )
        live_snapshot = unit_of_work.snapshots.add_live_snapshot(
            live_inventory,
            discovery_run_id=discovery_run.id,
        )
        comparison_record = unit_of_work.findings.add_comparison_result(
            comparison_result,
            expected_snapshot_id=netbox_snapshot.id,
            observed_snapshot_id=live_snapshot.id,
        )
        return {
            "discovery_run_id": discovery_run.id,
            "netbox_snapshot_id": netbox_snapshot.id,
            "live_snapshot_id": live_snapshot.id,
            "comparison_record_id": comparison_record.id,
        }
```

## 6. Historical Comparison Support

### Repeated Discovery Architecture

The system is designed to support repeated discovery and historical trending:

1. **Discovery Run Record**
   - Each discovery execution creates an immutable `DiscoveryRunRecord`
   - Stores: target, timestamp, status, metadata
   - Multiple runs preserve history

2. **Snapshot Association**
   - Each live snapshot is linked to a discovery run via `discovery_run_id`
   - NetBox snapshots are independent (no run association needed, canonical source)
   - Full lineage preserved

3. **Historical Timeline**
   - `HistoryRepository.timeline()` merges discovery runs + comparisons
   - Ordered by creation time (newest first)
   - Enables UI visualization of network changes over time

4. **Comparison Linkage**
   - Each comparison links specific expected (NetBox) + observed (live) snapshots
   - Enables retrospective analysis
   - Can compare any NetBox snapshot against any live snapshot

### Use Cases Enabled

- **Drift Analysis:** Compare latest discovery against baseline NetBox state
- **Trend Detection:** Multiple discoveries show device/interface churn
- **Audit Trail:** Full immutable record of what was observed when
- **Anomaly Detection:** Identify unusual patterns across multiple runs
- **Change Tracking:** See how device attributes evolve

def _build_runtime_services(settings: Settings):
    # 1. NetBox connectivity
    netbox_client = NetBoxClient.from_settings(settings, response_cache=None)
    netbox_service = NetBoxService(client=netbox_client)
    
    # 2. Inventory synchronization
    inventory_service = InventoryService(
        context=ServiceContext(settings=settings),
        netbox_service=netbox_service,
        inventory_mapper=InventoryMapper(netbox_mapper=NetBoxInventoryMapper()),
        cache=build_cache_backend(settings.redis_url),
    )
    
    # 3. Transport management
    transport_manager = TransportManager()
    transport_manager.register(NetmikoSSHTransport())
    transport_manager.register(ParamikoSSHTransport())
    transport_manager.register(PySnmpTransport())
    transport_manager.register(HttpxTransport())
    
    # 4. Collector registry
    parser_registry = ParserRegistry()
    parser_registry.register(CiscoInventoryParser())
    collector_registry = build_cisco_inventory_registry(transport_manager)
    
    # 5. Collector executor
    collector_executor = CollectorExecutor(
        collector_registry=collector_registry,
        transport_manager=transport_manager,
        parser_pipeline=ParserPipeline(registry=parser_registry),
        normalization_engine=NormalizationEngine(),
        snapshot_repository=_InMemorySnapshotRepository(),
        metrics=CollectorRuntimeMetrics(),
    )
    
    # 6. Collector runtime
    scheduler = CollectorScheduler()
    dispatcher = CollectorDispatcher(executor=collector_executor, scheduler=scheduler)
    collector_runtime = CollectorRuntimeEngine(
        scheduler=scheduler,
        dispatcher=dispatcher,
        metrics=collector_executor.metrics,
    )
    
    return inventory_service, collector_runtime
